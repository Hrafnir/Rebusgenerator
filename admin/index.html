Inviter til organisasjonen

Google Maps for organisasjonen

Hvordan lager jeg en Google Maps API-nøkkel?
  1. Gå til Google Cloud Console og opprett eller velg et prosjekt.
  2. Aktiver Maps JavaScript API og Places API.
  3. Opprett en API-nøkkel under APIs & Services -> Credentials.
  4. Begrens nøkkelen til nettstedet ditt under Website restrictions, for eksempel GitHub Pages-domenet.
  5. Lim nøkkelen inn her og lagre.

Bjørnsveen kan bruke Bjørnsveen sin nøkkel. Andre organisasjoner må legge inn sin egen nøkkel.
